# WebSeKai

[Agent 写的技术文档](/Technology.md)

> [!TIP]
> 本项目使用 **WorkBuddy** 作为 Agent 工具，模型为 **DeepSeek V4.1 Flash**

## 概览
基于 [Astro](https://github.com/withastro/astro) 为框架打造的个人博客模板

字体使用`Noto Sans`（SC 作为主字体，JP 作为日语后备字体），符号字体使用[`FluentUI System Icons`](https://github.com/microsoft/fluentui-system-icons)

## 快速开始
点击仓库右上角的 *Use this template*，将仓库以模板的形式复制到自己的 GitHub 账号

### GitHub Pages
仓库创建完成后，前往`Settings` → `Pages`，将`Source`从`Deploy fron a branch`切换为`GitHub Actions`，等待构建完成即可

### Vercel
仓库创建完成后，前往 **Vercel** 并登录自己的账号，然后点击右上角的 **Create New** → **Project**，授权 GitHub 账号后选择你刚刚创建完成的仓库 **Import**，点击 **Deploy**，等待构建完成

**Vercel 的自带域名国内大概率访问不了，建议绑定域名使用**
